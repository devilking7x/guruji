# 🏫 Guruji — School Pilot Kit (Teachers ke liye)

> **1 page me sab kuch:** ye kit kisi bhi school/teacher ko Guruji ka classroom pilot shuru karne ke liye kaafi hai. Printing ke liye `/poster` page bhi hai.

---

## Kya hai Guruji?

Guruji ek **Hindi-first AI tutor** hai — Classes 6 se 10 tak (Maths/Science). Baccha Hindi ya English me sawal poochhta hai, aur Guruji seedha jawab nahi deta — **hint deta hai, sochwata hai**, jaise ek achha teacher. Notebook chapter ke hisaab se NCERT-grounded jawab milte hain.

---

## Classroom me kaise shuru karein (5 steps, ~10 minute)

1. **Poster lagao** — `/poster` page kholo, A4 par print karo, classroom ke board par lagao.
2. **Bacche scan karein** — poster par QR code hai; bacche apne phone se scan karke Guruji kholen.
3. **Class select karo** — pehli baar khulne par baccha apni class (6–10) chunta hai. Koi naam/phone/account nahi — sab **anonymous** hai.
4. **Pehla quiz lo** — Quiz tab me apne topic par 5 sawal ka quiz. Guruji level ke hisaab se mushkil adjust karta hai.
5. **Teacher dashboard dekho** — Teacher tab me poori class ka anonymous view: kaunse topics kamzor hain, kitne quizzes hue, kaunsi class active hai.

---

## Privacy note 🔒

- Guruji **koi naam, phone number, address ya school ka naam nahi maangta.** Sirf ek nickname + class.
- Notebook ke photo (Copy check) **process-and-discard** hote hain — kabhi save nahi hote.
- Teacher dashboard me **sirf anonymous aggregates** dikhte hain (3 se kam students par "insufficient data"). Kisi bacche ka naam/ID teacher ko kabhi nahi dikhta.

---

## Teacher dashboard kaise dekhein

1. Guruji me **Teacher** tab kholo.
2. Apni **class (6–10)** select karo.
3. Dekho: kitne students active hain, topic-wise average mastery, **sabse kamzor topics**, hafte ke quizzes, active streaks.
4. Worksheets tab se kamzor topics ki **printable practice sheets** nikaal kar class me de do — ek click me print.

## FAQ

**Internet kitna lagega?**
Normal browsing jaisa hi. Ek quiz ya chat session me kuch MB se zyada nahi. School Wi-Fi ya ek phone hotspot kaafi hai.

**Kya free hai?**
Haan — students aur teachers dono ke liye free. Guruji Code for a Billion hackathon ka open-source project hai (MIT license).

**Bacchon ka data safe hai?**
Haan. Naam/phone kabhi store nahi hote, photos save nahi hoti, aur teacher dashboard me sirf anonymous class-level numbers dikhte hain.

**Exam ke liye syllabus covered hai?**
Classes 6–10 ke Maths/Science ke **111 NCERT chapter summaries** built-in hain — jawab chapter citation ke saath aate hain. Out-of-syllabus sawalon ko Guruji politely refuse karta hai.
